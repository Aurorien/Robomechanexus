# Robomechanexus
Robotics management workshop

*** Under development ***

Published on cloud service Render:   
[https://robomechanexus.onrender.com/](https://robomechanexus.onrender.com/)

## Overview

- **`/frontend`** - React + TypeScript + Vite application
- **`/backend`** - Node.js + Express API with PostgreSQL ([see backend/README.md](backend/README.md))

## Quick Start

**Backend:**
```bash
cd backend
npm install
# Configure .env file (see backend/.env.example)
node index.js
```

**Frontend:**
```bash
cd frontend
npm install
npm run dev
```
